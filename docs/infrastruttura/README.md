| ----------------------------------------------------------- | ------------------------------------------------------------- |
| [Avvisi dei lavori dell'account](avvisi-lavori-account.md)  | Arriva una issue `allarme` sui lavori automatici dell'account |
| [Chiave della prova dei consensi](chiave-prova-consensi.md) | Custodia della chiave, rotazione, verifica dopo un ripristino |
